# Nutrileaf e-commerce starter

This is a free-hosting-friendly storefront prototype for Nutrileaf.

## Included
- Responsive storefront
- Product categories
- Product cards
- Working shopping cart using browser local storage
- Cart totals and remove buttons
- Newsletter UI
- Mobile layout
- Placeholder branding/art

## Important
Checkout is intentionally a demo. Before accepting real orders, connect a payment provider (such as Stripe or PayPal), decide how inventory/order records will be stored, and add the business's final policies, contact information, product photos, ingredients and legally appropriate labeling/disclosures.

## Free hosting
This static version can be deployed to Cloudflare Pages or Netlify. No GoDaddy subscription is required for hosting.
